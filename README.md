# 🎨 Figlog (피그로그)

> **Figma에서의 실제 작업 시간을 스마트하게 기록하는 macOS 메뉴바 앱**
>
> Figlog는 Figma 창이 활성화되어 있고 사용자가 실제로 조작하고 있는 시간을 자동으로 감지하여 기록하는 macOS 전용 유틸리티 앱입니다. 메뉴바에서 한눈에 오늘의 집중 타임라인을 파악하고 관리해보세요!

---

## 📥 설치 방법 (Installation)

> [!IMPORTANT]
### [👉 Figlog 최신 버전 다운로드 (Download Latest Version) 👈](https://drive.google.com/file/d/1oCJsITSRtXmA9hLBvTi2aVJR1Udiv-yJ/view?usp=sharing)

1. 위의 **다운로드 링크**를 클릭하여 설치 파일을 다운로드합니다.
2. 다운로드된 `Figlog.app` 파일을 **애플리케이션(Applications)** 폴더로 드래그 앤 드롭합니다.
3. 앱을 실행하면 macOS 상단 메뉴바에 Figlog 아이콘이 표시됩니다.
4. *참고: 최초 실행 시 Figma의 활성화 여부를 감지하기 위해 **손쉬운 사용(Accessibility)** 권한 허용이 필요할 수 있습니다.*

## 💻 사용 방법 (Usage)

### 1. 실시간 포커스 트래킹
* Figma 앱이 활성화(Active)되어 있고 포커스 상태일 때 자동으로 집중 시간 측정이 시작됩니다.
* 마우스 움직임, 키보드 입력 등 실제 사용자의 반응을 감지하여 미사용 상태(Idle)를 제외한 진짜 작업 시간만 기록합니다.

### 2. 메뉴바 타임라인 & 세션 확인
* 메뉴바 아이콘을 클릭하면 오늘 하루 동안 진행한 작업 세션들이 **타임라인 스트립(Timeline Strip)** 형태로 한눈에 보여집니다.
* 각 세션 바에 마우스를 올리면(Hover), 시작 시간, 종료 시간 및 총 집중 시간이 **네이티브 툴팁**으로 명확하게 표시됩니다.
* 짧게 끊어진 세션(2분 이내의 간격)은 타임라인 가독성을 위해 자동으로 병합되어 시각화됩니다.

### 3. 유연한 환경 설정 (Settings)
* **Launch at Login**: 맥이 켜질 때 자동으로 Figlog가 시작되도록 설정할 수 있습니다.
* **Grace Period**: 작업 도중 잠깐 한눈을 팔거나 다른 앱을 보더라도 세션이 끊기지 않고 유지되도록 대기 시간(초 단위)을 설정합니다.
* **Break Reminder**: 일정 시간 연속으로 작업할 경우, 건강을 위해 휴식을 취하도록 리마인더를 띄워줍니다.

## 🛠️ 개발 현황 (Current Status)

로컬에서의 데이터 무결성과 트래킹 안정성을 극대화하기 위해 다음과 같은 핵심 아키텍처 개선을 완료했습니다.

* **안정적인 파일 기반 JSON 저장소**:
  * 기존 `UserDefaults` 방식에서 탈피하여 파일 시스템(`Application Support/com.figlog.Desktop/records/`) 기반의 구조화된 JSON 영속성 스토리지를 구축했습니다.
* **이중 안전 저장 메커니즘**:
  * 작업 중 세션 데이터 분실을 막기 위해 핵심 이벤트 기반 실시간 저장(Event-driven Save)과 5분 주기의 안전 자동 저장(Safety Autosave)을 병행합니다.
* **시스템 슬립/웨이크 보호 (Delta-Tick)**:
  * 맥이 잠자기 모드(Sleep)로 들어가거나 깨어날 때(Wake) 발생할 수 있는 시간 측정 왜곡(Gap)을 감지하고, 3초 임계값을 초과하는 비정상 시간 누적을 완벽히 차단합니다.
* **UI/UX 폴리싱**:
  * 타임라인 간격 병합 및 호버 가이드 툴팁 추가, 설정창 UI 마진 조정을 완료하여 깔끔한 레이아웃을 제공합니다.
  * 설정 변경 시 디버그 로그가 명확하게 출력되도록 검증 시스템을 구성했습니다.
